# Walkthrough 6.2 – Zooh!

Aufgabe 4 (Gruppe, ca. 13 min) kann nur mit echten Personen durchgeführt werden. Diese Vorlage ist
vorbereitet: Szenario durchspielen, pro Screen **höchstens einen Befund in einem Satz** eintragen
(ohne Namen), Screenshot pro Key Screen ins Board legen oder im Ordner `docs/screenshots/` ablegen.

Szenario Persona: «Kaufen Sie zwei Tickets und zeigen Sie das Ticket am Drehkreuz.»
Weg: Start → Ticket kaufen → Mein Ticket (alternativ: Start → Gruppenbesuch → Ticket kaufen → Mein Ticket;
Start → Lageplan → Fütterung → Programmpunkt).

Prüffragen pro Screen: Weiss die Person, was sie tun kann? Sieht sie, dass ihre Aktion gewirkt hat? Findet sie zurück?
